# True Duel

True Duel es un juego movil 1v1 por turnos, pensado para partidas cortas, tension constante y decisiones con impacto.

## Objetivo del juego

El objetivo es derrotar al campeon rival en combates rapidos donde importan tanto la estrategia como la adaptacion durante la partida.

## Enfoque general

- Combate por turnos, facil de entender y con profundidad para dominar.
- Sistema competitivo basado en habilidad, sin pay-to-win.
- RNG controlado para aportar variedad sin quitar control al jugador.

## Estado del proyecto

Este repositorio contiene la planificacion del MVP y una base inicial de implementacion para frontend y backend.

## Stack

- Flutter (frontend movil)
- PHP Symfony (backend API)
- PostgreSQL + Redis
